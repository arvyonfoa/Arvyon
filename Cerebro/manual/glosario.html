      Capítulo 8

      Glosario y preguntas frecuentes

      Todas las palabras nuevas del manual, en orden alfabético y con buscador.

      Glosario

      Agente
      Un programa de IA que no solo responde, sino que ejecuta tareas: lee archivos, escribe, busca en la web, hace commits. Claude Code es un agente.
      AGENTS.md
      Archivo con las instrucciones para agentes distintos de Claude Code (OpenCode, Codex). En Arvyon remite a CLAUDE.md.
      Alfabetización en IA
      Saber usar la IA con criterio y de forma segura. El Reglamento Europeo de IA pide a las empresas que forman a su personal en esto.
      API
      La forma en que dos programas se comunican. Una automatización usa APIs para conectar, por ejemplo, WhatsApp con una hoja de cálculo.
      Branch / rama
      Una línea de trabajo paralela en Git. Los cambios se hacen en una rama y se unen a main con un pull request.
      Callout
      Recuadro de color en Obsidian. En el cerebro marcan Hecho, Estimación, Supuesto, Por verificar y Contradicción.
      CLAUDE.md
      Archivo de reglas que Claude Code lee al trabajar en una carpeta. Es el esquema operativo del cerebro.
      Claude Code
      El agente de Anthropic para trabajar con archivos y código. Se usa en la web, el escritorio, el teléfono o la terminal.
      Clonar
      Descargar una copia completa de un repositorio a tu computador.
      Commit
      Una foto guardada de los cambios, con un mensaje. Forma el historial del repositorio.
      Conflicto
      Cuando dos ramas cambian las mismas líneas de forma distinta y hay que elegir a mano.
      Conectores
      Integraciones de Claude con servicios como Gmail, Google Drive o Notion. Funcionan sin añadir sus dominios al entorno.
      Dataview
      Plugin de Obsidian que crea tablas automáticas a partir de la ficha de las páginas. Lo usa el tablero.
      Diff
      La comparación entre el antes y el después de un archivo.
      Entorno en la nube
      La configuración guardada con la que arrancan las sesiones de Claude Code: acceso a la red, secretos, script y variables.
      Esquema
      La capa de reglas del cerebro: CLAUDE.md, AGENTS.md y el prompt maestro.
      Fase 1 / Fase 2
      Las dos fases de Arvyon: Aprender (9 nov – 15 dic de 2026) y Actuar (cuando se cumplan los criterios de paso).
      Force push
      Subir cambios reescribiendo la historia de una rama. Peligroso; Claude Code lo tiene bloqueado.
      Frontmatter
      La ficha entre líneas --- al principio de cada página: tipo, área, estado, confianza, resumen, fuentes y fechas.
      Fuente
      Material original que se guarda en raw/ y se resume en wiki/14-fuentes/.
      GitHub
      El servicio en internet donde vive el repositorio con todo su historial.
      Índice (index.md)
      El catálogo de todas las páginas del cerebro. El agente lo lee primero en cada consulta.
      Ingesta
      Darle una fuente al agente para que la lea, la resuma y la integre en todas las páginas afectadas.
      JSON
      Formato de texto en el que viajan los datos entre aplicaciones.
      Laguna
      Un dato que falta o que hay que verificar. Se anotan en wiki/_meta/lagunas.md.
      LLM
      Modelo de lenguaje grande, como Claude, GPT o Gemini.
      main
      La rama principal del repositorio: la versión oficial del cerebro.
      Markdown
      Formato de texto sencillo con títulos (#), listas (-) y enlaces. Todas las páginas del cerebro están en Markdown.
      Merge / unir
      Juntar los cambios de una rama con otra. Al unir un pull request, sus cambios pasan a main.
      Método 4D
      El método de trabajo de Arvyon: Descubrir, Diseñar, Desplegar y Demostrar.
      n8n
      Herramienta de automatización sin código, la más usada por la competencia que atiende pymes en Colombia.
      Obsidian
      Aplicación gratuita para leer y navegar archivos Markdown enlazados. Es el lector del cerebro.
      OpenCode
      Agente de código abierto que funciona en tu computador; lee AGENTS.md.
      Prompt maestro
      El documento completo con el rol, las reglas, los flujos, la agenda y el currículo del cerebro (PROMPT-MAESTRO.md).
      Proxy
      Un intermediario por el que pasan las conexiones de la máquina en la nube. Filtra sitios y añade credenciales por fuera.
      Pull
      Bajar a tu computador los cambios que hay en GitHub.
      Pull request (PR)
      Solicitud para unir los cambios de una rama a main, con revisión previa.
      Push
      Subir commits a GitHub.
      RAG
      Técnica en la que el modelo busca fragmentos de documentos en cada pregunta. No acumula conocimiento, a diferencia de la wiki LLM.
      raw/
      La carpeta de fuentes originales. Nunca se modifica.
      Registro (log.md)
      El diario cronológico del cerebro. Solo se añaden entradas.
      Repositorio
      La carpeta de un proyecto en GitHub, con todo su historial. El de Arvyon es arvyonfoa/Arvyon.
      Revert
      Un commit que deshace otro sin borrar la historia.
      Revisión de salud
      El programa herramientas/revisar_wiki.py, que encuentra enlaces rotos, páginas sin ficha, huérfanas o vencidas.
      Script de configuración
      Programa que se ejecuta al crear la máquina de una sesión, antes de que arranque Claude, para instalar herramientas.
      Secreto de red
      Clave de API guardada en el entorno que el proxy añade a las peticiones sin que Claude la vea.
      Segundo cerebro
      Una colección ordenada de lo que sabes, guardada fuera de tu cabeza. En Arvyon la mantiene un agente.
      Sesión de estudio
      El flujo de la Fase 1: estudias, el agente ingiere tus apuntes, explica, propone un ejercicio y comprueba lo aprendido.
      Tesis
      La síntesis viva del negocio: 8 hipótesis con su estado. Está en wiki/00-panorama/tesis-arvyon.md.
      Variable de entorno
      Valor de configuración que leen los comandos de la sesión. No sirve para claves.
      Wiki LLM
      Una wiki escrita y mantenida por un modelo de lenguaje: el patrón en el que se basa el cerebro.
      Wikilink
      Un enlace entre páginas escrito como [[nombre-de-pagina]].

      No hay términos con esa palabra. Prueba con otra.

      Preguntas frecuentes

      ¿Tengo que escribir las páginas yo?

      No. Tú das fuentes e instrucciones; el agente escribe. Si quieres corregir algo, díselo y él lo cambia.

      ¿Qué pasa si cierro el chat sin pedir commit?

      Lo que no se subió a GitHub se pierde cuando la máquina de la sesión se recupera. Pide siempre «haz commit y push» antes de terminar.

      ¿Puedo usar otro agente que no sea Claude Code?

      Sí. OpenCode y otros leen AGENTS.md. Si notas que no siguen las reglas, pégales el prompt maestro completo.

      ¿Por qué el agente no une los pull requests él mismo?

      Porque la decisión de qué entra en la versión oficial es tuya. Así siempre sabes qué cambió.

      ¿Qué hago si un PR tiene conflictos?

      Pide al agente que traiga main a la rama y los resuelva. Después revisas y unes.

      ¿Cómo deshago algo que ya uní?

      Pide un revert: un commit nuevo que deshace el anterior sin borrar la historia.

      ¿Puedo guardar contraseñas en el cerebro?

      No. Ni en el repositorio ni en las variables de entorno. Las claves van como secretos de red, y nunca se pegan en el chat.

      ¿Cada cuánto se actualiza este manual?

      Solo cuando el fundador lo pide. Cada cambio sube la versión y queda en el historial de la portada.
