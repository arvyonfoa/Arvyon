# Unit economics

## En una frase
Son los números por cliente que dicen si el negocio funciona cuando crece.

## Métricas y fórmulas
| Métrica | Fórmula | Meta inicial (por definir) |
|---|---|---|
| **CAC** (costo de adquirir un cliente) | (Publicidad + horas de venta × tarifa) / clientes nuevos | |
| **Margen por paquete** | (Precio neto de impuestos y comisiones − costos directos) / precio neto | |
| **Tarifa efectiva por hora** | Ingreso neto del proyecto / horas reales invertidas | |
| **LTV** (valor del cliente en su vida) | Margen del proyecto inicial + (margen mensual del acompañamiento × meses de permanencia) | |
| **LTV / CAC** | LTV / CAC | ≥ 3 (heurística común) |
| **Abandono mensual** | Clientes que cancelan el acompañamiento / clientes activos al inicio del mes | |
| **Meses de recuperación del CAC** | CAC / margen mensual por cliente | |
