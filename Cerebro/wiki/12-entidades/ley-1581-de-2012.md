# Ley 1581 de 2012 (protección de datos personales)

## Qué es
Es la ley estatutaria colombiana que regula el tratamiento de datos personales (habeas data). La autoridad de control es la [[sic]].

## Relevancia para Arvyon
Arvyon promete aplicar el estándar europeo «según la Ley 1581» ([[posicionamiento]]). Hay que dominarla para la política de datos propia y para la de cada cliente.
