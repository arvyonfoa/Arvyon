# Sectores prioritarios

## En una frase
Empezar con dos sectores para que cada caso de éxito sirva de ejemplo al siguiente cliente ([[presentacion-socios-2026-10]], diapositiva 5). La propuesta es **comercio y servicios** ([[dec-004-sectores-para-empezar]]).

## Matriz de atractivo (por completar)
Puntúa de 1 a 5. Atractivo = dolor × capacidad de pago × facilidad de llegar × casos de uso rápidos.

| Sector | Volumen de empresas | Dolor repetitivo | Capacidad de pago | Facilidad de llegar | Casos de uso en < 30 días | Total |
|---|---|---|---|---|---|---|
| Comercio (minorista y mayorista) | alto (≈41 % de las mipymes) | | | | | |
| Servicios profesionales (contables, jurídicos, consultoría) | alto (≈40 % de las mipymes, servicios en general) | | | | | |
| Salud privada (clínicas, odontología, estética) | | | | | | |
| Educación (colegios privados, academias) | | | | | | |
| Inmobiliario | | | | | | |
| Logística y transporte | | | | | | |
| Turismo y hotelería | | | | | | |

> [!tip] Supuesto
> Los servicios profesionales pueden ser mejor primer nicho que el comercio: tienen más tareas documentales, márgenes más altos y además sirven como **canal** (un contador atiende a decenas de pymes). Ver [[nichos-y-alianzas]].
